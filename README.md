#Storylog API
A backend service to manage user stories, logs and moods.

#Setup instructions
1-Create folder
2-Initialize project using - npm init
3-create index.js file for main logic
4-Install Dependencies
5-Start the server

#Features/API Overview
-User Auth(JWT)
-CRUD for stories
-Mood tracker endpoints
